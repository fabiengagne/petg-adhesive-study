# PETG Adhesive Study

Experimental comparison of adhesives for bonding FDM-printed PETG parts, with an application to waterproof mechanical assemblies used in the Amavia self-positioning buoy project.

## Repository structure

- `publication/french/` — French version of the technical publication
- `publication/english/` — Future English version
- `media/photos/` — Experimental setup, specimens, adhesives, failure modes, and application photos
- `data/` — Experimental data and future structured datasets

## Current status

The French publication is the current working version. An English version and additional experimental photographs will be added later.
